# Repository instructions

- Keep project documentation in `README.md` and implementation progress in
  `TRACKING.md`. Update only those documentation files unless the user
  explicitly requests another file.
- Do not commit ad hoc plans, design documents, agent notes, execution ledgers,
  or other workflow artifacts, including files under `docs/superpowers/`.
  Keep temporary working notes outside the repository, for example in `/tmp`.
- These repository conventions override skill defaults that call for saving
  or committing plan documents. Only add such documents if the user explicitly
  requests them.
- When completing a tracking item, check it off and strike through its text;
  keep the item visible rather than deleting it.
